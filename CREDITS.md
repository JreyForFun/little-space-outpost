# Credits

## Artwork

All game art is generated by scripts in this repository. The art direction is in
[docs/ART-DIRECTION.md](./docs/ART-DIRECTION.md).

| Asset | How it is made |
| --- | --- |
| `assets/buildings/*` (7 buildings, idle + running) | `tools/blender/render_assets.py`: models built from code, cel-shaded with ink outlines |
| `assets/astronauts/*` (5 crew sprite sheets) | Blender frames → `tools/compose_sheets.py` |
| `assets/characters/*` (Rio, Sage and Lumi with 3 expressions each; ASTRO with 4) | `render_assets.py` (portraits) |
| `assets/environment/*` (Moon equator, Moon pole and Mars sites and maps; Earth; title tiny-planet; nebula sky) | Blender terrain + `compose_sheets.py` (procedural nebula, stars, Mars sky) |
| Icons, panels, buttons, patches and effects | Drawn in code (`src/ui.js`) |

Regenerate everything with:

```bash
blender -b --factory-startup --python tools/blender/render_assets.py
python tools/compose_sheets.py
```

The original competition art kit, whose creator and license were never recorded, has been fully
replaced and removed.

## Sound and music

All sounds and the music are synthesized live with the Web Audio API (`src/audio.js`). There are
no audio files.
